# Player

Player de  músicas em Python, com suporte a rádio online e Podcasts. 

Implementação do Podcast utilizou a API do iTunes e radio o Radio-Browser.
Interface foi construída com Flet. 

Integração com Drive/streaming via internet das músicas foi cancelada e será removida em breve. 


# Para executar

Instale o requirements.txt e rode o run.py.
